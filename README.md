# Курсовой проект по модулю ООП

**Приложение для получения и анализа вакансий с hh.ru**  
Использует ООП-подход, работу с API и хранение данных в JSON-файле.

## Описание проекта

   Проект включает модули

- **vacancy** — служит для работы с вакансиями; поддерживает методы сравнения вакансий между собой по зарплате и валидацию данных, которыми инициализируются атрибуты.

- **vacancy_api** — служит для работы с платформой hh.ru. Реализованные классы умеют подключаться к API и получать вакансии.

- **vacancy_storage** — содержит методы для добавления вакансий в файл, получения данных из файла по указанным критериям и удаления информации о вакансиях.


## Установка:

1. Клонируйте репозиторий:
```bash
git clone https://github.com/CyberLeo92/coursework_2_oop.git
```
2. Установите зависимости:
```
poetry install
```
## Использование:

Запустите приложение через консоль:
```bash
poetry run python -m main
```

## Тесты:
- Для тестирования используются `unittest`, `mock` и `patch`.
- Покрытие тестами составляет ~86% (по результатам pytest-cov).
